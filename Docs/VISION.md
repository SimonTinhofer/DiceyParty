# Vision for Dicey Party

The goal is to create a fun online multiplayer party game. It is inteded to be played in the browser, should be mobile compatible and played with 3 - 5 people. The onboarding Process needs to be as frictionless as possible only requiring either Create or Join + Choose open Lobby. The game is basicly just a collection of smaller MiniGames.
Which Solutions does this Project use: <br/>
- Networking: Fishnet
- WebGL Transport: Bayou Plugin for Fishnet
- Dedicated Server Hosting: Edgegap
- Backend: Node.js server hosted on render.com
